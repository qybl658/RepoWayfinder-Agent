在当前任务目录实现一个仅用 Python 标准库的本地记录服务 server.py 和 README.md。使用本机已有 Python，不安装依赖，不请求其他模型。接口为 python server.py --host 127.0.0.1 --port PORT --db state.sqlite3，PORT 可由调用者指定；仅绑定 loopback。SQLite 文件保存数据，服务重启仍能读回，首次运行自动建表。业务代码、数据库和自己创建的临时验证文件留在本任务目录；正常 CLI/MCP 运行日志和缓存不算业务文件。

HTTP 合同：GET /health 返回200及 JSON {"ok":true}。POST /items 接收 JSON 对象 {"text":"非空文本"}，保存原文本（含中文），返回201及 JSON {"id":正整数,"text":原文本}，id 自动递增。GET /items 返回200及 {"items":[{"id":...,"text":...}]}，按 id 升序。GET /items/ID 返回200及单条 {"id":...,"text":...}；不存在的正整数 id 返回404。损坏 JSON、非对象、缺少text、text不是字符串或仅空白都返回400，且不得插入记录；未知路径返回404。错误应为正常 JSON 响应，不使服务退出。

运行并实际核对健康、中文写入/查询、错误请求不新增记录，以及停服重启后数据仍在。核对后停止本次自己启动的服务；不要结束无关进程。README 简述启动命令、接口和实际验证。交付可再次按上面接口启动，不要留下常驻服务。完成时报告相对路径和实际结果。


范围：只读写当前任务目录内的业务文件，不读取目录外业务文件或其他任务产物；系统工具、已安装运行时及其正常使用文档除外。
